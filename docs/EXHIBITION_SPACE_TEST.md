# Exhibition experiment (independent test branch)

In Exhibition Walk, arrange saved models in the 20 x 20 floor grid, then click **Make space**. Each measured footprint becomes a support at the same point. Generated support height is 3.35 + 0.48 h + 0.025 h squared metres, where h is measured source height; minimum circulation clearance is 2 m outside support plots. Real mesh cross-sections control taper and offsets. Upper corners and protrusions seed curved stems that split into two limbs, with a narrow central crown and smooth implicit unions joining the roof. The mesh has one continuous closed surface and approximately 0.24 m roof thickness; no source mesh is overwritten. It is procedural geometry rather than AI architectural reconstruction.

Material generation copies small overlapping source-texture fragments with least-error seam paths. Capture uses the source base maps without display lighting. Fine weathering, contrasting pigments and source texels are preserved rather than quantised or averaged into a grey palette. It excludes cutout margins and neutral white background. One clamped, non-repeating UV field covers each spatial region with filtered sampling. Physical opaque materials with gentle clearcoat retain colour, lit depth and ambient reflection without tone-map desaturation. Human view projects cached colour from the overhead surface onto the floor along the sunlight direction. This is an efficient filtered-light approximation, not path-traced refraction; the geometry remains fully opaque, while steel and lower supports still cast real shadows. The coloured light belongs to the room preview and is not baked into GLB exports.

**Enter space** chooses a clear spot and restores WASD navigation. Supports constrain movement. The white gallery starts at 12 m high and extends if needed. Original yellow footprints remain on the axis floor with normal depth testing, so the generated solid occludes them.

Human view has clear glazing, 22 real steel grid beams and warm directional sunlight casting shadows onto the floor. One 2048 px shadow map is cached until the scene changes; walking only redraws the visible view. Steel and glass are hidden in axis view. **Sound on/off** controls nearby exhibit audio. The first user click unlocks playback. The nearest model within approximately 4.2 m of its footprint fades in; source model audio also belongs to its generated column at the same grid position. Two audio elements crossfade between exhibits and remember playback positions. Switching to axis view, opening an editing/model panel, leaving the viewport or hiding the tab fades out. Records with an audio association use it directly; legacy compositions can derive one from archive metadata. Audio never requires a new generation job.

**Original models** restores the editable exhibition; edits mark the previous space out of date. **Export GLB** downloads geometry and embedded appearance textures. Original placements are never replaced. A small local recipe rebuilds the active preview after refresh.

The first agent has a 0-50 model slider. It runs one local generation at a time, randomly chooses the Las Vegas-to-V&A or V&A-to-Las-Vegas workflow, and automatically saves completed models in the floating workspace library and the existing saved gallery. **Stop** finishes/saves the current job and skips queued jobs. Missing local generation capability leaves an editable collage; it does not report that models were generated. No new hosted service or paid API is introduced.

The second agent imports up to 50 library models only when the floor is empty. When exhibits already exist, it rearranges those exact placements without adding or removing any model. Large varied square footprints are packed tightly around the physical floor centre regardless of the panned camera target with one full white cell between every pair, including diagonal neighbours. Scale stays near the footprint size (90-99%) and rotation uses 90, 180, 270 or 360 degrees. Selected-model dropdown, button, handle and keyboard rotation use the same quarter-turn steps. A whole proposed layout is validated and applied atomically. Up to 100 one-cell placements can fit with the white gap; an impossible collection leaves the current layout intact. Library contents and floor layouts remain private to this browser/device.

Audio uses varied credible metadata matches; when these are weak or exhausted it falls back to a random archive audio, avoiding the most recent 24 choices where possible. The basis is recorded in linkedMedia. Existing version-1 saved associations are upgraded once on opening while preserving their video, saved camera, model bytes and group. Videos stay muted.

Validation: npm run build; py -3.14 scripts/check_project.py; node qa/verify_canopy_geometry.mjs; node qa/verify_canopy_growth.mjs. The geometry audit checks a single welded closed connected surface for distant supports, finite attributes, retained sizes and unchanged original buffers/materials. Browser validation uses isolated test data and intercepted generation responses with actual GLB fixtures, without running AI inference, to check batch count/directions, saving, stop, layout, audio diversity/migration, walking, texture export and mobile width.

The accepted shared main and the public site are unchanged. This experiment stays on work/chenyiwei/exhibition-testing until reviewed.

Linked-video metadata updates keep the same player/time when URLs are unchanged. Video arrow keys no longer navigate the model carousel. Network/decode read errors and prolonged buffer stalls have up to three reload attempts preserving the last playback position; Stop/model changes cancel recovery. Proxy timeout after response headers closes the stream rather than appending JSON to video bytes.
