# 白色展厅：用作品改写空间

Windows 双击原有 START_TEAM_WEBSITE.cmd，进入 `/exhibition.html`。本机快捷方式“拉斯维加斯展览创作”也会打开同一工作室。需安装团队素材包；现成模型组合不依赖 AI 运行环境。

第一次进入时，7 件原始招牌雕塑位于白色展厅。原有漫游、拖拽、旋转、缩放、镜像、多选、复制粘贴和照片功能继续保留。

## 观众怎么使用

1. 在右侧模型库点击 ＋，或选择左侧展品后点击“复制到工作台”。
2. 用已有控制工具移动、旋转、缩放模型，组合成新的雕塑，也可以给作品命名。
3. 选择展位，点击“放入展览”。组合中每个模型的空间位置、旋转和比例会保留，不需要先进行 AI 生成。
4. 展厅根据被观众改写的展位数量逐步显色；色调取自组合画面中的有色像素。地面、墙面、穹顶和灯光随作品变化。以 7 个展位作为完整显色周期，其余展位仍可继续放作品。
5. “撤销替换”可恢复上一次布置。“返回白色起点”恢复原始雕塑及白色空间，保留工作台中的组合，而且这次恢复也可以撤销。

如果想先看完整变化，点击“载入策展示例”。《借来的城市 / Borrowed Worlds》包括七组实际组合：借来的地平线、垂直的记忆、反向的宫殿、霓虹的花冠、折叠的旅馆、路边的仪式、城市的回声。均使用已有招牌模型，不包含 AI 生成的新几何体。

## 保存和分享

- 展厅布置与工作台草稿分别保存在当前浏览器的 IndexedDB。刷新后可以继续；不同浏览器、不同电脑的作品不会自动合并。
- “导出展览”生成 JSON，保留展位、模型组合、变换、名字和空间色调；安装相同素材包的组员可用“载入展览”继续创作。
- JSON 引用团队原有模型文件，不包含完整素材包；如果作品使用另行生成的模型，也需要单独分享对应模型。
- “导出组合 GLB”导出实际 3D 组合，可用于 Blender 或其他支持 GLB 的创作工具；“导出拼贴 PNG”导出当前画面。
- 导入会先验证全部模型并准备成功，再替换当前展览。失败的导入会保留已有布置。
- 这次使用新展厅存储空间，不删除原来展厅、拼贴工作室或模型历史的数据。

## 开发验证

运行 `npm ci`、`npm run build`、`python scripts/check_project.py`，以及：

```text
node --test qa/exhibition-loop/white-gallery.test.mjs
```

Windows 构建通过 Node 读取和解析模块，兼容允许读取项目文件、但限制列举父目录的工作环境。源文件和生成的两个展览 bundle 需要一起提交。

本机浏览器检查使用独立的 Microsoft Edge 测试会话，不读取用户的浏览器草稿。验证覆盖：白色初始空间、7 个真实模型、组合后直接替换、GLB 导出、刷新恢复、再次组合、撤销、恢复白色、JSON 导入导出、无效导入保护、策展示例及手机宽度。
