# Automatic archive composition

The Exhibition Walk preview cards include an Archive Agent with one Compose + generate button. It selects four transparent Las Vegas cutouts, assembles editable city layers, matches their silhouettes to real V&A photographic sculpture fragments, and submits the sculpture collage through the existing local TripoSR client. The generated model uses the ordinary preview/drag-to-exhibit flow and inherits one video and audio association. Edit collage opens the regular tools; Previous collage restores the composition and model present before the agent replaced them.

Planning uses existing image descriptions, tags, object names, mask resolution and shape proportions. It chooses among borrowed monuments, roadside symbols and invented skylines; broad forms form a base, tall shapes a crown, and signs/accent forms overlap them. Recent objects and themes are penalised for variety. This is a local metadata-and-shape planner, not a new conversational language-model API. The shared shape matcher is also used by Collage Studio; only selected sculpture images are loaded. City/V&A tabs edit one connected layer stack. Users can replace a counterpart, turn it 90 degrees or rematch its shape. The generated PNG contains V&A fragments; source Las Vegas layers and V&A credits are retained. The 3D stage is the existing AI service; it retains the same geometry/quality limitations.

Image preparation is atomic: missing cutouts are retried up to three times and cannot replace the existing collage unless every selected city and V&A cutout decodes. Concurrent generation/editing is guarded while the agent is active. No new media datasets, AI weights or paid API credentials are required. Without an available generation runtime, the editable collage remains and the page states that 3D generation is unavailable. Previous collage is a session backup; normal drafts and saved models retain their existing browser storage.

Validation: project syntax/catalog checks plus ten isolated browser integration checks covering the one-click path, editable source layers, model placement, source media, previous-work restoration, missing-cutout recovery a mobile/no-runtime case, saved sculpture source records, exact V&A-versus-city PNG checks, manual regeneration and original Collage Studio compatibility. Existing GLB fixtures intercepted generation requests; these tests do not run GPU inference or establish the quality of newly generated geometry. No public website deployment.
